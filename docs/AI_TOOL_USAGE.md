# AI Tool Usage

**ChatGPT Codex** was used as an AI coding assistant during project development.

The tool supported the following work:

- reviewing and organizing the assessment documents and Excel dataset;
- comparing the application with the assessment requirements;
- planning the application workflow and folder structure;
- supporting backend, RAG and interface implementation;
- creating tests for normal, ambiguous, conflicting and unsafe requests;
- investigating Windows setup, embedding download, Groq API and interface issues; and
- improving setup, architecture, testing and product documentation.

Generated suggestions were checked against the supplied agreements, policies, product guide and workbook. The application was run locally with different customer accounts and prompts. Automated tests were also used to verify the behaviour.

AI assistance supported development and review. Important controls remain visible and testable in the repository. Customer authorization, source precedence, calculations and action confirmation are enforced by deterministic application code.
